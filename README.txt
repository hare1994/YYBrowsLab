מעבדת הגבות של יובל יעקב

מה זה: אתר סטטי (קובץ אחד: public/index.html). זיהוי הפנים רץ בדפדפן של הלקוחה, בלי שרת ובלי מפתח.
התמונה לא נשלחת לשום מקום.

אירוח: Cloudflare Workers (חינם).
- Cloudflare מחובר לריפו הזה ב-GitHub. כל דחיפה (push) ל-main מעדכנת את האתר אוטומטית תוך דקה-שתיים.
- ההגדרות נמצאות ב-wrangler.jsonc. הקבצים שמתפרסמים הם רק מה שבתיקייה public.
- public/_headers מגדיר כותרות אבטחה בסיסיות.

שינויים נפוצים:
- מעבר לדומיין חדש: ב-public/index.html לעדכן את הכתובת ב-og:url וב-og:image (התצוגה המקדימה כשמשתפים את הקישור).
- תמונת התצוגה המקדימה: public/og.jpg (1200x630). אייקונים: favicon-32.png, icon-192.png, apple-touch-icon.png.
- מספר הוואטסאפ: בקובץ public/index.html מחפשים WA = ומחליפים את המספר (פורמט בינלאומי, בלי + ובלי 0).

בדיקה מקומית (לא חובה):
  npx wrangler dev   ואז לפתוח http://localhost:8787

חשוב:
- האתר צריך חיבור לאינטרנט אצל הלקוחה, כי מנוע הזיהוי (כ-4MB) נטען מ-cdn.jsdelivr.net ו-storage.googleapis.com בפעם הראשונה.
- לבדיקה: פתחי את הקישור בטלפון, העלי תמונה ישרה באור טוב, ובדקי שקווי המדידה יושבים על הגבות.
