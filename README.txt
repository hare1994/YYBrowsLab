מעבדת הגבות של יובל יעקב: הוראות העלאה (5 דקות, חינם)

מה זה: אתר סטטי (קובץ index.html אחד). זיהוי הפנים רץ בדפדפן של הלקוחה, בלי שרת, בלי מפתח ובלי חשבון Claude.
התמונה לא נשלחת לשום מקום.

העלאה ל-Netlify (הכי פשוט):
1. נכנסים ל-app.netlify.com/drop (אפשר בלי הרשמה, עם הרשמה האתר נשאר קבוע).
2. גוררים לשם את התיקייה brow-lab (או את הקובץ index.html).
3. מקבלים קישור. אפשר לשנות את שם האתר בהגדרות (Domain settings).

חלופות חינמיות: GitHub Pages, Cloudflare Pages, Vercel.

חשוב:
- האתר צריך חיבור לאינטרנט אצל הלקוחה, כי מנוע הזיהוי (כ-4MB) נטען מ-cdn.jsdelivr.net ו-storage.googleapis.com בפעם הראשונה.
- אם רוצים לשנות את מספר הוואטסאפ: בקובץ index.html מחפשים WA = ומחליפים את המספר (פורמט בינלאומי בלי + ובלי 0).
- לבדיקה: פתחי את הקישור בטלפון, העלי תמונה ישרה באור טוב, ובדקי שקווי המדידה יושבים על הגבות.
